# 06 · 구현 순서

각 단계는 **그 단계만으로 쓸 수 있는 상태**로 끝낸다. 다음 단계를 기다리는 반쪽짜리를 만들지 않는다.

## 1단계 · 계산 엔진 ★ 여기가 제일 중요 (2~3일)
